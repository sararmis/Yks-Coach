# Yapay Zeka

Bu klasör, projenin Yusuf tarafından geliştirilen yapay zeka bileşenlerine ayrılmıştır.

Burada tutulacak içerikler:

- Python kaynak dosyaları
- Algoritmalar ve formüller
- Claude ve diğer yapay zeka modelleri için prompt metinleri
- Yapay zeka bileşenlerine özel test ve bağımlılık dosyaları

Yapay zeka tarafıyla ilgili yeni dosyalar bu klasörün dışında oluşturulmamalıdır.
